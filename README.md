# Sabor Express

Web independiente de Manus preparada para GitHub Pages.

## Publicar
1. Crea un repositorio en GitHub.
2. Sube todo el contenido de este proyecto.
3. Haz push a la rama `main`.
4. En GitHub ve a **Settings → Pages** y selecciona **GitHub Actions** como origen.
5. El workflow desplegará la web automáticamente.

No necesita servidor, base de datos ni servicios de Manus.
